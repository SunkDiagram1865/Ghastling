# Ghastling Website

## 项目简介

欢迎来到**小乐魂启动器**（Ghastling Launcher）的官方网站！

本项目基于 GitHub Pages 静态网页部署，为 Ghastling 启动器提供简洁、美观的品牌展示页面。



## 在线访问

 [https://sunkdiagram1865.github.io/Ghastling](https://sunkdiagram1865.github.io/Ghastling)



## 项目结构

本仓库包含以下核心文件与目录，其余文件（如打包生成文件、上游 Modrinth Website 及分支 Axolotl Website ）遗留内容，与本项目无关。

```.
/
├── index.html # 网站主页面
├── ghastling.png # 小乐魂图标
├── ghastling_background.png # 小乐魂（带背景）
├── sounds/ # 网站音效资源目录
│ 	   └── *.ogg # 音效文件
└── README.md # 项目说明文档
```



## 本地开发与预览

### 安装依赖
```bash
pnpm install
```

### 启动开发服务器
```bash
pnpm run website:ghastling
```
