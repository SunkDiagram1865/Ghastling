# Ghastling Launcher
开源，新一代的全版本启动器

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

**Ghastling Launcher** 是由 **SunkDiagram1865 (cysunk)** 开发的免费开源 Minecraft 启动器

⚠️ **项目状态：规划中（尚未开始开发）**

本项目基于以下仓库进行二次开发：

- **上游**：[Modrinth APP](https://github.com/modrinth/code)
- **分支**：[Axolotl Launcher](https://github.com/Mystic-Stars/Axolotl)

本分支专注于 **Windows x64** 平台的桌面启动器体验，是使用 [Modrinth](https://modrinth.com/) 与 [CurseForge](https://www.curseforge.com/) 公共 API 的独立非官方客户端。
