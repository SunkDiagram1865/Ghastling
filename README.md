# Ghastling
开源，新一代的全版本启动器

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL--3.0-blue.svg)](LICENSE)

**Ghastling Launcher** 是由 **SunkDiagram1865 (cysunk)** 开发的免费开源 Minecraft 启动器

本项目基于 [Modrinth APP](https://github.com/modrinth/code) **（上游）**与 [Axolotl Launcher](https://github.com/Mystic-Stars/Axolotl) **（分支）**仓库进行二次开发**（二次分支）**，专注于 Windows x64 的桌面启动器体验。它是使用 [Modrinth](https://modrinth.com/) 与 [CurseForge](https://www.curseforge.com/) 的公共 API 独立非官方客户端，与 **Spark Universe** 和 **Overwolf Ltd.** 不存在隶属或背书关系。

> 此分支由 **SunkDiagram1865 (cysunk)** 一人进行开发与维护，所以分支开发状态**不活跃**
